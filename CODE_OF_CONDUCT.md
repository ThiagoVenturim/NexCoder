# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussions about the work and
never harass anyone. Report unacceptable behavior privately to the maintainer
through GitHub (ThiagoVenturim). Reports are handled confidentially.

## Ethical usage commitment

All contributors and users of `nexcoder` must follow our [Ethical Usage Policy](USAGE_POLICY.md):

- Use `nexcoder` to protect websites and applications, contribute to open-source projects, and improve software quality — never for malicious purposes.
- Run automated tests, captures, and security scans only against targets you own or where you have explicit written authorization from the owner.
- Follow coordinated vulnerability disclosure through official project security channels ([SECURITY.md](SECURITY.md)), without publishing exploits or offensive proof-of-concept code.
