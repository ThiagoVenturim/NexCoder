# Ad Copywriting and A/B Testing

Systematic framework for turning technical product capabilities into high-converting advertising copy across search and social ad channels.

## Principles

1. **Strict Character Constraints**
   - Google Search: Headline <= 30 characters, Description <= 90 characters, Path <= 15 characters.
   - LinkedIn Sponsored Content: Intro text <= 150 characters for immediate mobile visibility; Headline <= 50 characters.
   - Meta / Instagram: Primary caption with first 125 characters serving as the core hook before truncation.
   - Twitter / X: Full message <= 280 characters with dedicated CTA link token.

2. **A/B Testing Variants**
   - Variant A (Speed & Pain): Targets developer frustration with slow feedback loops, brittle tooling, and manual boilerplate.
   - Variant B (Governance & Control): Targets engineering leaders with auditability, privacy, zero data leakage, and offline verification.

3. **Ethical Guidelines**
   - No misleading benchmarks, exaggerated performance multipliers, or deceptive clickbait.
   - No emojis in ad headlines or body strings.
   - All links must direct exclusively to verified official repositories or documentation pages.
